# zeroMER — channel branding

All materials are deliberately separated from the Bandit City game source.

## Folders
- `01-youtube-banner/` — YouTube channel banner, SVG, 2560×1440.
- `02-youtube-avatar/` — YouTube avatar, SVG, 1024×1024.
- `03-obs/` — OBS overlay, SVG, 1920×1080.

## Visual direction
- Brand spelling: **zeroMER** (exact capitalization).
- Theme: SAMP / GTA, sunset city, palm trees, sports cars, street graffiti.
- Palette: asphalt black, sunset orange, warm cream, muted burgundy.
- Stream target: Full HD 1920×1080.

## OBS notes
The overlay SVG has a transparent gameplay area. Add it as an Image source above the Game Capture source. Add webcam and chat sources underneath/inside their marked areas as needed. The decorative frames are starting layout guides; adjust source positions to match your actual webcam and chat dimensions.

## Important
These are editable vector starter assets, not rendered MP4 animations. Intro/outro video exports and audio are not included yet.
